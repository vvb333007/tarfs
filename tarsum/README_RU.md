# tarsum

`tarsum` — небольшая консольная утилита для добавления **контрольных сумм CRC64/ECMA-182** в TAR-архивах.

Утилита предназначена для работы с **TarFS** и сохраняет контрольную сумму непосредственно в неиспользуемой области padding заголовка TAR, не изменяя стандартную структуру TAR-файла.

# Сборка в Linux и Windows

Выполните:

```sh
make tarsum
```

**ПРИМЕЧАНИЕ:** При сборке в Windows необходимо установить Cygwin.

## Использование

Для вычисления и встраивания контрольных сумм в TAR-архив выполните:

```text
tarsum input.tar   --> создаёт "output.tar"
```

или:

```text
tarsum input.tar my_fs.tar    --> создаёт "my_fs.tar"
```

Полученный TAR-архив будет содержать контрольные суммы CRC64, которые впоследствии могут быть проверены TarFS.

Исходный TAR-архив не изменяется — утилита создаёт новый файл.

## Принцип работы

Заголовок TAR имеет размер 512 байт и содержит неиспользуемую область padding в последних 12 байтах.

`tarsum` использует первые 12 байт этой области для хранения 8-байтовой контрольной суммы CRC64/ECMA-182 и небольшого маркера:

```text
[ 0x00 ]['C']['6']['4'][ 8-байтовая контрольная сумма CRC64/ECMA-182 ]
```

ASCII-сигнатура `C64` используется только для визуальной идентификации и игнорируется TarFS.


Упрощённо это выглядит следующим образом:

```text
┌───────────────────────────────┐
│         Заголовок TAR         │
│                               │
│  Метаданные файла             │
│  Имя файла                    │
│  Размер файла                 │
│  ...                          │
│                               │
│  [ Контрольная сумма CRC64 ]  │
└───────────────────────────────┘
              │
              ▼
          Данные файла
```

TarFS может обнаружить встроенную контрольную сумму и проверить целостность соответствующих данных (см. параметр `CONFIG_TARFS_INTEGRITY` в `src/config.h`).

Если данные были повреждены, проверка целостности завершается ошибкой, и TarFS сообщает об ошибке ввода-вывода — в частности, устанавливает `errno` в `EIO`.

Если повреждены метаданные файловой системы (например, имя файла), TarFS возвращает стандартную ошибку `ENOENT` вместо `EIO`.
